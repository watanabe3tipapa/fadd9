Why ABCなぜテキストで楽譜なのか

TYPE: TEXT

そのまま書ける

楽譜が ASCII テキスト。エディタさえあれば今日から書けて、 コピペで誰かに渡せる。特別なソフトは要らない。

TYPE: GIT

履歴で育つ

譜面は diff を持つ。練習の改変が一行ずつ残り、 「先月の自分」との差分がそのまま上達の記録になる。

TYPE: PLAY

貼って即再生

abcjs など対応ツールに貼れば、その場で鳴って絵になる。 音と譜面と文字が同じ場所に住む。

Roadmapこれからの fadd9

  1. PHASE 2 Samples Library ✅

    data/samples.json を正本にした一覧・検索・詳細ページを公開(12 譜例)。

  2. PHASE 3 Play & Render ✅

    詳細ページで楽譜描画と再生。abcjs v6 をローカル同梱し、外部通信ゼロを維持。

  3. PHASE 4 Reference & Playground ✅

    ABC記法チートシート、入力しながら鳴るプレイグラウンド、Fadd9 OS への統合。

  4. PHASE 5 Grow the Library

    指弾き・スライド・モード別スケールなど譜例を増強。再生中の音符ハイライトも視野。
