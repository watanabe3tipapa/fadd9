ABC記法とはテキストで書く楽譜

ABC記法は、ASCII文字だけで楽譜を書く記譜法です。1991年に Chris Walshaw が開発し、 フォーク・伝統音楽のコミュニティで広く使われています。ギターのリフからオーケストラまで、 テキスト1行で音楽を記述できます。

TEXT

そのまま書ける

楽譜が ASCII テキスト。エディタさえあれば今日から書けて、 コピペで誰かに渡せる。特別なソフトは要らない。

GIT

履歴で育つ

譜面は diff を持つ。練習の改変が一行ずつ残り、 「先月の自分」との差分がそのまま上達の記録になる。

PLAY

貼って即再生

abcjs など対応ツールに貼れば、その場で鳴って絵になる。 音と譜面と文字が同じ場所に住む。
